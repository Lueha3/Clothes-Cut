# Clothes-Cut — 다중 옷입히기 프로그램 기획안 (v2, 2026-08-20)

> 사진 몇 장으로 만든 평생 아바타에 옷을 드래그해 입히고, 색은 토큰으로 정확히 깔맞추고,
> 이미지와 영상까지 한 프로그램 안에서 끝내는 숏폼 패션 콘텐츠 스튜디오.

## 1. 문제와 해결 컨셉

| 문제 | 해결 |
|---|---|
| ① 도구 파편화 — ChatGPT/이미지 생성기/Higgsfield를 오가며 수십 번 재생성 | 워크플로 통합: 한 캔버스에서 착장 → 생성 → 영상 |
| ② 영상마다 모델 이미지를 다시 넣어야 하고 얼굴이 매번 달라짐 | 평생 아바타: 사진 몇 장 → 계정에 영구 저장, 최대 10명 |
| ③ 모델 간 같은 계열 색(네이비/그레이)의 색·채도가 미묘하게 어긋남 | 팔레트 토큰 + 생성 후 ΔE 자동 검증(Color QC) |

## 2. 핵심 기능

### 2.1 아바타 스튜디오 (최대 10명, 계정 귀속 영구 자산)
- 생성 경로 A: 레퍼런스 사진 1~5장 업로드 / 경로 B: 프로그램 내 프리셋+텍스트로 생성
- 확정 시 정면·측면·전신 3~4컷 **아바타 시트** 자동 생성 → 이후 모든 생성의 신원 기준
- 생성 결과를 얼굴 임베딩으로 시트와 비교, 유사도 미달 시 자동 재생성

### 2.2 드레스룸 — 스티커 슬롯 착장 캔버스
- 아바타 위에 부위별 빈 스티커 슬롯 7개(점선+아이콘)로 드래그 유도
  - 상의: 티 / 아우터 / 시계(손목) / 가방(어깨·손)
  - 하의: 바지 / 신발(발) / 벨트(허리)
- 파일 드롭 즉시 자동 배경 제거 + 비전 분류 → 잘못된 슬롯에 놓아도 올바른 부위로 자동 재배치
- 드롭된 아이템의 대표색 추출 → "팔레트에 추가할까요?" 제안

### 2.3 아이템 리컬러 — 클릭하면 색상 패널
- 착장 아이템 클릭 → 색상 패널: 팔레트 토큰 / HEX·HSL 입력 / 스포이드 / 채도·명도 슬라이더
- 원칙: **디자인·질감·로고는 그대로, 색상만 변경**
- 프리뷰는 클라이언트(Lab 색공간 색 이동, 즉시), 최종은 생성 모델 반영

### 2.4 팔레트 토큰 & Color QC (차별화 핵심)
- 색을 이름 붙은 토큰으로 관리: 모델 A 바지 = NAVY 토큰, 모델 B 상의 = NAVY 토큰 → 물리적으로 동일 HEX
- 토큰 수정 시 참조하는 모든 아이템 일괄 변경
- 생성 후 자동 검증: 의류 세그먼테이션 → Lab 대표색 측정 → 토큰과 CIEDE2000 ΔE 비교
  - ΔE ≤ 3 통과 / 3~6 마스크 색보정 / > 6 해당 부위만 부분 재생성(최대 2회)
- QC 리포트 UI: "모델 1 바지 NAVY ΔE 1.8 ✓"

### 2.5 씬 & 생성
- 씬 빌더: 저장 아바타 중 선택 배치(권장 2~4명), 배치·배경 프리셋, 무드 레퍼런스
- 이미지: 아바타 시트 + 아이템 + 토큰을 착장 지시서로 컴파일 → 멀티이미지 편집 모델 → Color QC
- 영상: 이미지를 시작 프레임으로 image-to-video (런웨이 워크/턴/포즈 전환/카메라 무빙, 5~10초)
- 추출: 9:16 기본(1:1·16:9 지원), PNG/MP4, 4K 업스케일 옵션

## 3. 화면 구성
① 아바타 스튜디오 ② 드레스룸(메인 캔버스) ③ 팔레트 ④ 생성·내보내기 ⑤ 라이브러리(옷장·히스토리)
— ②~④는 한 화면 좌(캔버스)/우(패널) 구조.

## 4. 기술 아키텍처
- 프론트: Next.js + TypeScript, Konva.js 캔버스
- 백엔드: Supabase(Auth·Postgres·Storage) + 작업 큐
- AI 게이트웨이: 모델 어댑터 계층(멀티벤더 교체 가능)

| 용도 | 1순위 | 대안 |
|---|---|---|
| 착장 합성·리컬러 | Gemini 2.5 Flash Image | Seedream 4.0 · FLUX.1 Kontext |
| 아바타 신원 유지 | 아바타 시트 첨부(zero-shot) | 인물별 LoRA (v2 프리미엄) |
| 영상 | Veo 3.x | Kling 2.x · Higgsfield API |
| 배경 제거 | BiRefNet | remove.bg |
| 의류 세그먼테이션(QC) | Grounded-SAM 2 | 패션 파싱(SCHP 계열) |

비용 러프: 이미지 $0.03~0.06/장, 영상 $1~3/컷 → 콘텐츠 1편 약 $3~8.

## 5. 로드맵
- **M0 프로토타입 (완료)** — 현재 브랜치: 업로드·2분할 드래그·톤 선택·Gemini/Veo 연동
- **M1 MVP (6주)** — 계정+아바타 10슬롯(사진 업로드) · 슬롯 7개 캔버스 · 배경제거+자동분류 · 클릭 리컬러(토큰+HEX) · 이미지+영상 생성 · 추출. 완료 기준: 신규 사용자가 10분 안에 1편 완성
- **M2 색 보증 & 씬 (4주)** — Color QC 루프 + 리포트 · 프로그램 내 아바타 생성 · 다중 모델 씬 · 숏폼 규격. 완료 기준: 동일 토큰 부위 ΔE ≤ 3 자동 달성
- **M3 자산화 & 수익화 (6주+)** — LoRA 아바타 · 옷장 재사용 · 템플릿 · 팀 공유 · 구독 과금

M1 착수 전 1주: 이미지 편집 모델 3종 벤치마크(동일 지시 20세트로 일관성·색 준수율 비교).
